# design/ — 벡터 원본

앱이 CSS로 그리는 오브제를 SVG로 옮긴 것. **디자인 도구에서 열려고 두는 자리지
앱이 읽는 자리가 아니다.** `public/`에 넣지 않은 이유가 그것이다 — 거기 두면
빌드에 실려 나가고 `public/sw.js`의 선캐시 목록과 어긋난다.

| 파일 | 크기 | 원본 |
|---|---|---|
| `cassette.svg` | 316×190 | `src/components/Cassette.tsx` + `globals.css` `.cassette` |
| `cassette-player.svg` | 360×276 | `src/app/intro/page.tsx` + `globals.css` `.player-shell` |
| `reference/*.png` | 3배 | **앱이 실제로 그리는 모습.** SVG에서 뺀 그림자가 여기 다 있다 |

**`reference/`를 먼저 봐라.** SVG는 형태와 색만 옮긴 것이고, 앱이 실제로 어떻게
보이는지는 PNG가 기준이다. 둘을 나란히 놓고 작업하면 된다.

카세트가 300이 아니라 316인 것은 SIDE 배지가 `left: -13`으로 몸체 밖에 걸치기
때문이다. 몸체 좌상단은 여전히 (0,0)이다.

## 트레이싱이 아니다

원본이 CSS 도형이라 좌표를 그대로 옮겼다. 옮긴 뒤 dev 서버에 실제 마크업을
주입해 `getBoundingClientRect`로 재고, SVG 쪽은 `getBBox`로 재서 맞췄다
(2026-08-06). 라벨·창·릴·하단 트랩·키 다섯 개·카운터가 **소수점 둘째 자리까지
일치**한다. 글자 베이스라인도 계산이 아니라 실측값이다 — 계산하면 한글 글꼴의
줄상자 때문에 2~3px씩 어긋난다.

## 알고 쓸 것

- **글자는 패스가 아니라 `<text>`다.** 고칠 수 있는 대신 글꼴이 없는 자리에서는
  다르게 그려진다. 필요한 것 — `Gamja Flower`(손글씨 라벨) · `Black Han
  Sans`(88) · `Noto Sans KR`(헤드·배지). 아웃라인이 필요하면 도구에서 변환해라.
- **`Share Tech Mono`는 앱에서도 안 뜬다.** 카운터·키 각인·`A ▸`가 그 글꼴을
  부르는데 `layout.tsx`의 `@import`에 없다 — 실제로는 시스템 monospace로
  그려진다. SVG는 원본 CSS를 그대로 적어 두었다. 고치려면 앱 쪽을 먼저 고쳐라.
- **그림자 28개 중 8개만 들어 있다.** 딱 떨어지는 것(나사 링·배지 그림자·키
  아래 턱·상단 하이라이트)만 살렸고 **블러가 들어간 20개는 전부 뺐다.** 벡터
  도구가 SVG 필터를 잘 못 읽어서, 넣으면 오히려 편집이 어려워진다. 대신
  `reference/`의 PNG에 그 20개가 다 들어 있다. 특히 두 곳이 크게 다르다 —
  카세트 창의 `inset 0 2px 6px`(파인 느낌)과 플레이어 `.deck-window::after`의
  inset 4개(테이프가 **안에 들어가** 보이게 하는 것). 지금 SVG에서는 테이프가
  도어 위에 붙인 스티커처럼 평평하다.
- **움직임은 없다.** 앱에서는 릴이 돈다(`.reel.spin`, 감긴 양에 따라 2~4.9초).
- 박혀 있는 값 — 카세트는 `progress 50` · SIDE A · 「아버지의 믹스테이프」,
  플레이어 안의 테이프는 인트로 그대로 `progress 12` · 「소영에게 — 1988. 9. 17.」.
  플레이어 키는 PLAY만 살아 있는 상태(인트로와 같다).
- **플레이어에 손글씨 메모("눌러주세요.")는 넣지 않았다.** 그건 플레이어가
  아니라 소영이 붙인 쪽지다 — `globals.css`도 "플레이어 표면에는 아무 문구도
  넣지 않는다"고 적어 두었다.

## 고칠 때

**앱이 원본이다.** `globals.css`를 고쳤으면 이 파일들은 낡은다. 손으로 좌표를
옮기지 말고 위의 실측 절차를 다시 밟아라.
