### 2. 대본 파이프라인을 뒤집었다 (`413d178`)

**`docs/SCRIPT.md`가 이제 대사의 원본이다.** `src/lib/cues.ts`는 받아 적는 쪽이다.

전에는 반대였다 — `cues.ts`가 원본이고 SCRIPT.md는 뽑아낸 사본이라, 글을
고치면 **사람이 손으로 옮겨 적어야 했다.** 그 한 칸 때문에 "문서를 고치면
나머지가 따라온다"가 성립하지 않았다.

```bash
npm run script:check    # 무엇이 바뀌는지만 본다
npm run script:bake     # 되쓰기 → 금지어 → 바뀐 줄만 굽기 → 길이 → sw 버전
```

**`scripts/script.mjs`** 가 양방향을 맡는다(`apply` / `dump`).
되쓰기는 세 갈래로 갈라 보고한다:

| 갈래 | 처리 |
|---|---|
| `<br>`만 다름 | 되쓰되 **굽지 않는다** — `generate-audio.mjs`가 `<br>`을 걷어낸 뒤 해시하므로 캐시 키에 없다 |
| 글자가 다름 | **그 줄만** 다시 굽힌다 |
| 줄 수가 다름 | 그 큐를 통째로 다시 굽고 `durationSec`을 다시 잰다 |

**멈추는 경우 둘** — 큐 집합이 어긋날 때(`trigger`·`next`·`ui`는 대본이
표현하지 못한다. `cues.ts`에서 먼저 만들고 `npm run script:dump`),
그리고 번호 없는 줄을 만났을 때(조용히 사라지는 것이 제일 무섭다).

**`scripts/fix-durations.mjs`** 를 정식으로 올렸다. `generate-audio.mjs`는
`durationSec`을 읽고 **경고만** 한다 — 고치는 것은 이쪽이다. ffprobe가 없으면
조용히 건너뛴다(굽기 사슬 한가운데라 여기서 끊기면 곤란하다).

**파이썬을 버렸다.** 이 PC에서 `python`이 WindowsApps 스텁에 가려 실행되지
않고 `py` 런처도 없다. npm 스크립트로 엮이는 도구가 거기서 끊기면 자동화가
의미가 없다. `scripts/dump-script.py`는 지웠다.

**CRLF 주의** — `cues.ts`는 전부 CRLF다. 파이썬 텍스트 모드는 알아서
변환해줬지만 Node는 아니다. `script.mjs`·`fix-durations.mjs`가 읽을 때 LF로
맞추고 쓸 때 되돌린다. 안 그러면 한 줄만 고쳐도 835줄이 전부 바뀐 것으로 잡힌다.

**검증** — 아무것도 안 고친 상태에서 되쓰기를 돌렸을 때 `cues.ts`가 한 글자도
안 바뀌는 것(`git diff --exit-code`)을 먼저 확인했고, 위 세 갈래와 번호 없는
줄까지 실제로 만들어 분류를 확인했다.

### 4. 사진 업로드를 고쳤다 (`71f60c9` + Vercel 설정)

**원인이 둘이었다.**

**(가) 배포본이 없는 버킷을 불렀다** — Vercel 환경변수
`NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET`이 옛 이름 `bonghwang-memories.appspot.com`
이었다. 그 버킷은 **404**(없음)이고 진짜는 `.firebasestorage.app`(403 — 존재하고
규칙 동작 중)이다. `next.config.js`의 `env` 블록이 이 값을 **빌드할 때 코드에
박아 넣어서**, 환경변수만 바꾸고 재배포해야 반영된다.

크롬에는 CORS 오류로 보였지만 CORS 문제가 아니다 — 없는 버킷이라 preflight가
404를 돌려주고 브라우저가 *"preflight … does not have HTTP ok status"* 로 표현한다.

→ **사용자가 Vercel에서 고쳐 재배포. 업로드 정상 확인됨.**

**(나) CSP가 blob:을 막았다** — 사진을 고르면 올리기 전에
`URL.createObjectURL`로 미리보기를 띄우는데 `img-src`에 `blob:`이 없었다.
**개발 서버에서는 안 드러나고 배포본에서만 막힌다.**

같이 찾은 것 — `media-src`가 아예 없어 `default-src 'self'`로 떨어지고 있었다.
「나의 육십 초」 녹음 되듣기도 배포본에서 막혀 있었을 것이다. 둘 다 열었다.
