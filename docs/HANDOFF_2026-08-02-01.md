## 0. 먼저 알아야 할 것

**대본을 고치는 자리가 바뀌었다.** 이제 `docs/SCRIPT.md`를 직접 열지 않는다.

```
/debug/script-edit (관리자)  →  「↓ SCRIPT.md로 내려받기」  →  npm run script:apply
        ↑ 서버 초안(config/scriptDraft)                              ↓
        어느 기기에서 열어도 같은 판                              cues.ts → 자막
```

- **서버 초안이 기본**이다. 어느 기기·어느 브라우저에서 열어도 같고, 개발
  서버를 껐다 켜도 남는다. 운영에서도 열린다(관리자만)
- 저장 전 수정은 **이 기기에도 담긴다**(localStorage). 화면이 새로 그려져도
  「저장하지 않은 수정이 남아 있어요 — 되살리기 / 버리기」로 되돌린다
- 자막까지 가려면 **내려받기 → `script:apply`** 를 거쳐야 한다. 서버 초안만
  고치면 앱은 옛 글을 계속 보여준다
- 소리는 또 별개다 — `npm run script:bake`

> ⚠️ **「되돌리기」와 「되살리기」는 정반대다.** 되돌리기는 원본을 다시 읽어
> 고친 것을 버린다. 되살리기는 임시 보관을 되살린다. 이름이 한 글자 차이라
> 다음에 「새로 불러오기」로 바꿀 것.

것이다. 첫 통화에서 소영이 직접 밝힌다(*"여자 목소리라 놀라셨나요?"*).

**거점 번호를 큐에 맞췄다.** 제목이 `A4`, 큐가 `B4_A`라 같은 곳을 두 글자로
불렀다. 문서는 `B1~B5`, 참여자 화면은 **글자 없이 숫자만**(`4 / 5 · 카페 탱자`) —
카세트가 SIDE A/B를 쓰고 있어 거기에 B를 또 넣으면 부딪힌다.

### 굽기

- 16개 큐 · `b1_walk` 신규 37초 · `fix-durations`가 실측으로 길이를 다시 적음

### 뜸(pause)은 코드로 한다

**음원에 무음을 굽지 않는다.** `subtitleLines[].pauseSec`에 초를 적으면 엔진이
그 자리에서 재생을 멈췄다 잇는다. 굽는 방식은 뜸을 고칠 때마다 그 줄을 다시
굽고 자막 시각을 통째로 다시 재야 한다.

대본에는 `(2s)` 같은 표기를 적지 않는다 — 자막에 그대로 나오고 TTS도 읽는다.
**아직 안 넣은 자리 셋:** `B1_B` 4번 · `B2_B` 3번 · `B4_RADIO` 1번.
`cues.ts`에 `pauseSec: 2`만 적으면 된다(굽기 불필요).

## 3. 넘어진 자리 (같은 실수를 반복하지 않도록)

**배포가 다섯 번 죽었다.** 대본 고치기 화면이 D6 금지어 목록을 글자 그대로
들고 있어서 `check-forbidden`이 그 파일을 잡았다. 빌드는 `next build` 전에
멈추므로 5~6초 만에 실패했고, 로컬에서 `tsc`·린트만 돌려 다섯 커밋을 지나서야
알아챘다. → **커밋 전에 `npm run check:forbidden`도 돌린다.**

예외 표식 `forbidden-check:allow`를 두되 **`.md`에는 안 먹는다** — 대사에
표식 한 줄로 금지어를 넣을 수 있으면 검사가 무의미하다.

**대본 내려받기가 세 번 깨졌다.**
- 초안을 통째로 써서 `SCRIPT.md`의 연표·인물·D규칙 해설이 날아갔다(git에서 복구).
  이제 `# 대본` 아래만 갈아끼운다
- 개정 표시 `✎`가 자막에 26곳 찍혔다. 확정본에는 검토 흔적을 남기지 않는다
- 칸에서 엔터를 치면 뒷부분이 번호를 잃었다. 이제 `<br>`로 바꾼다

**편집 중인 화면을 두 번 날렸다.** 소스를 고치면 dev 서버가 다시 컴파일하고
열려 있던 화면이 새로 그려진다. 사용자가 대본을 고치는 동안에는 코드를
건드리지 않는다.
