## 1. 이번 세션에 한 일

### Figma MCP를 붙였다

일러스트레이터로 그린 것을 앱 디자인에 반영할 수 있느냐는 물음에서 시작했다.
사용자가 세션 도중 Figma를 연결했고, 붙는 것까지 확인했다.

```
계정  맥스 / socialceos@gmail.com
팀    이권의 팀
좌석  View · tier starter        ← 여기가 걸릴 수 있다
```

붙은 뒤 할 수 있는 일 — 파일 구조 훑기 · 프레임의 레이아웃·색·간격을 **숫자로**
읽기 · **에셋을 코드 쪽에서 직접 내려받기**(벡터는 SVG, 사진은 원본) · 스크린샷으로
구현 결과 대조. 에셋 내려받기가 가장 큰 차이다 — 손으로 내보내 옮기는 단계가 없어진다.

**좌석이 `View`/`starter`다.** Figma의 개발용 읽기(`get_design_context`)는 보통
Dev 또는 Full 좌석을 요구해서 권한으로 막힐 수 있다. **실제 파일에 대고 불러 보지
않았으므로 막히는지 아닌지는 아직 모른다.** 막히면 스크린샷 + 에셋 내려받기로
우회할 수 있다.

**아직 파일 URL을 받지 못해서 아무것도 읽지 않았다.** `?node-id=`가 붙은 링크가
있어야 어느 화면인지 특정된다.

### `.ai`는 Figma도 못 읽는다

**Figma가 가져오는 것은 `.fig`·`.sketch`·이미지·SVG다.** `.ai`를 끌어다 놓으면
열리지 않는다. 그래서 MCP를 붙여도 **일러스트 → Figma 구간은 여전히 손이 간다.**

```
.ai  →  [일러스트에서 SVG 내보내기]  →  Figma에 끌어다 놓기  →  이후는 코드 쪽에서
```

일러스트에서 개체를 복사해 Figma에 붙이는 길은 macOS에서만 쓸 만하다 —
**여기는 Windows라 래스터로 붙거나 아예 안 붙는다.** 기대하지 말 것.

곧, 첫 칸에서 이미 SVG를 만들어야 하므로 **그림 한두 장이면 Figma를 거치는 것이
순 이득이 아니다.** Figma가 값을 하는 경우는 화면 시안 여러 장을 옮길 때다 —
색 토큰과 간격을 눈대중이 아니라 숫자로 읽을 수 있다.

### 이미지가 코드에 물리는 자리를 확인했다

디자인을 넣을 때 **세 곳이 함께 움직여야 한다.**

| 무엇 | 어디 |
|---|---|
| 인물 초상 | `src/lib/cast.ts:18` — `BASE = '/images/cast'` |
| 거점 사진 | `src/lib/tracks.ts:131` 이하 — `photo: '/images/place/t1.png'` |
| 능소화 오버레이 | `src/app/track/[n]/TrackPageClient.tsx:34` |
| **서비스워커 선캐시** | **`public/sw.js:28`~39 — 파일명이 하나하나 박혀 있다** |

**`sw.js`가 함정이다.** 이미지를 늘리거나 이름을 바꾸면 목록과 sw 버전을 같이
올려야 한다. 안 그러면 오프라인에서 그 이미지만 빠진다 — D8과 같은 결의 제약이다.

지금 `public/images/`에 있는 것은 PNG뿐이다(`cast/` 4장 · `place/` 4장 ·
오버레이 1장). `public/`의 `*.svg` 다섯은 Next.js 템플릿 잔재고 아무도 쓰지 않는다.
아이콘은 `QrIcon.tsx`처럼 인라인 `<svg>`로 들어가 있다 — 새 아이콘도 그 모양을 따른다.
