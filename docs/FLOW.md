## 진입

| 단계 | 화면 | 하는 일 |
|---|---|---|
| 랜딩 | `/` | 처음이면 '무료로 이야기 열기', 걷던 중이면 '이어서 걷기' |
| 계정 | `AuthModal` | 아이디(영문·숫자·밑줄 4~20자)·닉네임(2~12자)·비밀번호(6자 이상) |
| 프리로드 | `/download` | 음성 26개를 미리 받는다 — 골목에서 신호가 끊겨도 들린다(D8) |
| 인트로 | `/intro` | 테이프 → 쪽지 뒤집기 → 전화 → 통화 → '동행 시작' |

계정은 **선택이 아니다.** 랭킹·쿠폰·기록이 계정에 묶인다.
관리자는 `socialceos@gmail.com` 하나뿐이고 하드코딩이다(`src/lib/admin.ts`).

## 1막 — 거점 다섯

거점 진입은 **QR 또는 4자리 코드**다. 코드는 `src/lib/tracks.ts`의 `manualCode`.
만능 코드 `1111`은 '지금 차례 거점'으로 통과시킨다(현장에서 QR이 훼손됐을 때).

| 거점 | 미션 | 큐 흐름 |
|---|---|---|
| A1 봉황1935 | 개수 세기(정답 7) → 사장님 증언 → 사진 | `B1_A` → `B1_S` → `B1_B` |
| A2 미야상회 | 바나나우유 사진 | `B2_A` → `B2_B` |
| A3 능소화 고택 | 능소화 사진 (AR 폴백) | `B3_A` → `B3_B` |
| A4 카페 탱자 | 라디오 → **신청곡 퀴즈** → 나의 육십 초 | `B4_A` → `B4_RADIO` → `B4_B` → `B4_C` |
| A5 방하림 | 포스터 사진 → 증언 → B면 해제 | `B5_A` → `B5_T1~T3` → `B5_LETTER` → `B5_F` |

**A4가 유일하게 사진이 없다.** 라디오에서 아버지가 이문세 「소녀」를 신청하며
*"우리 딸, 영원히 지금처럼 웃는 소녀로 남았으면"* 이라고 말한다 — 딸을 '소녀'라
부르려고 그 곡을 고른 것이 이 장면의 핵심이라, 제목을 손으로 적어보는 퀴즈를 뒀다.

**A5만 조각이 없다.** `FragmentId`가 넷이고, 트랙 5는 그 조각들을 *끼워 넣는* 자리다.
쿠폰은 준다 — 소원은 '다음 주'로 유보되지만 가게에는 실제로 다녀왔다.

- [ ] **Firestore 규칙 배포.** 파일(`firestore.rules`)에는 있는데 서버에 게시되지
      않았다. `users/{uid}/points/{refId}` 생성이 `permission-denied`로 막혀
      포인트가 서버에 안 쌓이고, 그래서 랭킹에 아무도 뜨지 않는다.
      REST로 직접 확인함 — `users` 문서 업데이트는 200, `points` 생성은 403.
      `couponUses`(쿠폰 사용 확인)도 같은 이유로 막혀 있을 것이다.

      프라이빗 모드에서 IndexedDB가 막히는 것이 유력하나 재현 못 함.
