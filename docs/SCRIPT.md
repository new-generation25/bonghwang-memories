## 고치는 법

1. 이 파일에서 글을 고치거나 `<br>`을 옮긴다
2. `src/lib/cues.ts`의 같은 줄에 옮겨 적는다
3. 글자가 바뀌었으면 음성도 다시 굽는다 — `node scripts/generate-audio.mjs --only <파일명>`
   (`<br>`만 옮겼으면 굽지 않아도 된다. 음성에는 들어가지 않는다)

이 파일은 `python3 scripts/dump-script.py`로 다시 뽑는다.
