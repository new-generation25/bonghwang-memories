# EP.1 「아버지의 믹스테이프」 — 대본 개정안 v2 (검토용)

**이 파일은 검토용 초안이다.** 승인 전에는 `docs/SCRIPT.md`도 `src/lib/cues.ts`도
건드리지 않는다. 승인되면 `cues.ts`(신규 큐) → `SCRIPT.md` 순으로 반영하고 굽는다.

바뀐 줄에는 **✎** 를 붙였다. 표시가 없는 줄은 지금 대본 그대로다.

## 무엇이 바뀌나

| | 무엇 | 왜 |
|---|---|---|
| 2.1 | 테이프의 이름이 **강진욱** | 아들인 줄 알고 지은 이름. 태어나 딸이라 **소영으로 개명** |
| 2.1 | 목욕탕은 **한 번도 못 갔다** | "일곱 살까지 갔다"를 지운다. 아들 소원이 이룰 수 없게 된 것이 요점 |
| 2.2 | **소영도 다리를 다쳤다** | 아버지와 딸이 한 집에서 나란히 못 걷는다. 부재 사유가 물리적으로 분명해진다 |
| 2.3 | **가는 길 이야기 큐 신설**(`B1_WALK`) | 큰 나무 → 봉리단길 → **서부탕**. 목욕탕 자리를 서부커피로 옮긴다 |
| 2.4 | 첫 통화 도입 | 모르는 사람에게서 걸려온 전화임이 첫 줄에 드러난다 |
| 4.3 | 거점마다 **"○번째 이뤘네" + 방향** | 다음 행동을 소영의 말이 안내한다. 텍스트 의존을 줄인다 |

### 개명을 이야기 안에서 푸는 자리

테이프는 진욱을 부르는데 모두가 소영이라 부른다 — 기록자가 여기서 걸린다.
그래서 **첫 통화에서 소영이 직접 밝힌다**(`B0_CALL` 3·4번 신설). 한 번 말해두면
라디오의 "소영아", B면 편지의 "소영아", 방하림의 "강민수, 강소영"이 전부 그대로 산다.

**약 20줄이 새로 굽히고, 그중 6줄이 신규 큐다.** 나머지 100줄은 1.3의 전량 다시 굽기에
함께 들어간다.

### 대본 밖에서 함께 고칠 것 (`SCRIPT.md` 산문)

- **연표** — "소영 7세까지 일요일마다 목욕탕"을 지운다. 대신 *"아들인 줄 알고 남긴
  소원이라 한 번도 가지 못했다"*. **출생 직후 개명**(진욱 → 소영)을 1988.9.17 칸에 적는다
- **장소표** — A2의 옛 모습을 "옆 파란 타일 건물이 옛 목욕탕" → **"조금 못 미쳐 왼쪽에
  있던 서부탕(지금 서부커피)"**
- **인물** — 소영 항목에 부상을 적는다. **아버지의 부상과 원인이 다르다**(아버지는
  넘어짐, 소영은 계단에서 발목). 겹쳐 읽히지 않게 하는 것이 요점
- **어긋나 있는 것** — 라디오 사연의 "여섯 살"은 여전히 미정. 개명 설정과는 무관하다
